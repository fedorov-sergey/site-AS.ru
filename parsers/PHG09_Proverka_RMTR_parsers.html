Проверка РМТР

90. ПХГ/ПХ09 Проверка РМТР

Описание

Парсер извлекает информацию из всех файлов ГРАНД-Смета вида «ЛС» и выводит всю информацию из основной таблицы. Фильтр: только позиции, у которых «Обоснование» содержит «РМТР». Для каждой позиции ищет связанную смету по «Обоснованию» в той же папке и сравнивает её итог со строкой по столбцу «М».
